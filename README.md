# 声音小屋 · 给自己，留一点安静

默认全屏「雨夜书房」，39 种声音、12 个主题、25张生成画面与3段实拍循环视频。声音、换场景、播放和设置是首页的主要入口。

在线体验：[shengyin.kanglimin.com](https://shengyin.kanglimin.com/) · 基于 [Moodist](https://github.com/remvze/moodist) 改造。

## V2.5 实拍视频与离线

林间清晨、海边黄昏、星下篝火使用镜头固定的实拍片段，以片尾/片头交叠处理循环衔接。三个静音 H.264 视频合计约13.1 MB，均同源部署，作者与许可单独记录在 `assets/video-provenance.json`。配套静帧从循环第一帧提取，其他6个场景不变。

只在选中场景且开启动态时加载该视频。先显示静帧，视频后台加载并自动缓存，音频独立播放；保存当前空间或整包时会保存视频。通过缓存校验后以本机 blob URL 播放，断网重开仍可循环。切场景释放旧视频，页面隐藏/关闭动态/系统减少动态时暂停，不在多个场景同时解码。视频加载失败时保留静帧和可用的声音。

## 播放与离线稳定性

联网直接播放，无需先下载整包。声音下载完成后先解码播放，再后台保存；缓存写入慢、配额不足、缓存读取失败均不会阻塞在线播放。素材按内置清单校验长度和 SHA-256，损坏副本自动修复；网络失败自动重试一次，恢复联网后补试失败声部。暂停整包保存不会中断共用该请求的声音播放。

`media-index.js` 从 `assets/media-manifest.json` 生成，更新素材时须同步更新；构建会校验两份清单一致。

## 沉浸动态

雨夜书房、山间茶屋、灯下晚自习、老街雨巷、夜行列车、竹影夏昼保持原有 Canvas 轻动态。第5、6、7场景播放实拍视频时不叠加 Canvas 特效，关闭动态时显示对应静帧。

V2.4.1 仅收敛第5、6、7个场景：林间清晨只让瀑布内的原图水纹向下流动，取消前景水面扭动、雾、粒子和光斑；海边黄昏只保留低幅度海面起伏，取消绘制的波浪线和闪光；星下篝火保留局部微弱暖光和3颗淡火星，取消火焰图像变形。其余6个场景的动效函数保持原样，原有声音和素材缓存不变。

## 启动与手机预览

双击本目录 `启动预览.cmd`，保持窗口开启，访问窗口打印的 Local 地址，通常为 `http://localhost:4173/`。需要 Node.js，无需安装 npm 依赖。也可以在此目录执行 `node server.mjs`。

手机和电脑连接同一 Wi-Fi，访问启动窗口中的局域网地址。本次为 `http://192.168.1.6:4173/`，网络变化后以窗口地址为准。

请通过 HTTP 服务打开，直接双击 index.html 无法完整运行模块和缓存。

## 极简操作

- 首页上下或左右滑动切换主题，桌面可用方向键或滚轮。下次打开记住上次主题；首次为雨夜书房，始终主动点击才播放。
- 底部“声音”：正在听的声音独立调音，最多8层；“声音库”中播放按钮只试听，加号才加入混音。正在听的声音排在前面。
- 底部指南针“换场景”：打开9个主题选择。切换主题自动载入该主题配方；配方可提前保存。
- 右上设置：定时与专注、配方收藏、离线与存储、安装、轻动态。
- 原有收藏、配方、音量与上次主题会从 V1 自动迁移。清空声音后刷新仍保持空配方。

## 自动缓存与离线

可信地址下，声音与画面首次成功加载后写入浏览器 Cache Storage。以后直接读取本地，不重复下载。应用壳通过 Service Worker 缓存，断网后可以重新打开。

设置 → 离线与存储，可以查看大小与各主题状态，保存当前空间或全部声音、画面与视频，完整素材大小以页面显示为准。保存可暂停并继续，已经成功缓存的文件会被跳过。清理离线素材不会删除个人配方。

用户主动保存时会尝试申请持久存储，浏览器可能批准，也可能暂不批准；页面显示实际结果。缓存无法保证永久保留，用户主动清理网站数据、卸载或系统存储策略仍可能移除内容。

## 安装为手机应用

设置 → 安装声音小屋：

- 支持原生安装提示的浏览器会显示真实安装按钮。
- iPhone 在 Safari 中通过分享 → 添加到主屏幕，按系统提示开启作为网页App打开。不同版本菜单位置可能不同。
- 安装后从主屏幕打开，检查喜欢的场景是否完整离线保存；部分系统可能分开管理浏览器和主屏幕应用的存储。

**完整 PWA 安装与缓存需要 HTTPS 或 localhost 安全环境。** 正式地址支持安装与离线；普通手机局域网 HTTP 地址可试听和混音，完整 PWA 请使用正式 HTTPS 地址。

## 声音与画面

连续环境声使用各自长度的交叉淡化循环；雷声、翻书、颂钵、风铃和杯盏有随机间隔。按PCM能量与峰值做受限增益校正，不会无限放大底噪。场景画面先完成解码，再交叠切换；雨、雾、火星与水汽按场景区域显示，尊重系统减少动态设置。

新增蝉鸣、竹林、茶杯三种真实录音，逐项来源和 CC0 许可见 `assets/additional-sound-provenance.json`。原36种 Moodist 声音的逐文件授权映射仍缺失，不能冒称全部为 MIT/CC0；详见 `素材与授权.md`。所有画面为内置 imagegen 生成的写实场景，并非实地摄影。

## 限制与实现文件

手机后台与锁屏播放受系统和浏览器限制，仍需真实设备验证。定时器按绝对截止时间核对，系统冻结页面时可能延后执行。分享链接仅能在可访问当前地址的设备使用。

- `index.html`、`immersive.css`、`immersive-app.js`：当前主界面。
- `scene-view.js`、`scene-motion.js`：图片交叠、实景动态和滑动切换。
- `scene-film.js`：单视频生命周期、同源缓存、静音内联循环及静帧降级。
- `mixer.js`：当前混音与试听引擎。
- `offline.js`、`sw.js`：自动缓存、续传、存储及离线启动。
- `install.js`、`manifest.webmanifest`、图标：浏览器安装。
- `storage.js`、`data.js`：个人数据迁移、配方与声音配置。

后续修改应用壳文件应同步递增 `sw.js` 的 SHELL 版本，以使已经安装的浏览器获得完整更新。媒体清单记录哈希；未改变的素材跨版本保留。

## 构建与 Cloudflare 发布

不需要运行时依赖，Node.js 20+：

```sh
npm run build
npx wrangler deploy --config deploy/wrangler.jsonc
# 同步备用 Pages 站点
npx wrangler pages deploy dist --project-name shengyin --branch main --force
```

`dist/` 是白名单构建的发布目录，仅含现用页面、模块、图标、音频、画面与授权说明。Cloudflare Pages 使用直接上传；推送 GitHub 不会自动部署，修改后重新执行上述命令。

正式子域名使用 Cloudflare 管理的 Custom Domain DNS/TLS，直接由 Workers Static Assets 提供 `dist/`，避免声音先经 Worker 再访问 Pages 的额外回源环节。`deploy/asset-entry.js` 仅为声音补充字节范围响应，通过原生 ASSETS 绑定读取文件，不访问外部回源。资源不存在时返回 404，不把 HTML 当成成功的音频响应。备用站点为 `shengyin-72d.pages.dev`。更新时先构建，再发布正式站与备用站；仅推送 GitHub 不会自动更新这两个站点。旧代理源码保留作回滚参考。

代码遵循 MIT，保留 `LICENSE-Moodist` 上游声明。声音素材与代码采用不同许可，具体来源及上游逐文件授权映射缺失情况见[素材与授权](素材与授权.md)。请勿把集成音频当作 MIT 素材包再分发。


视频采用有界分段下载，完整校验后才写入离线缓存。应用更新限制并行下载并重试，失败时保留上一可用版本。
